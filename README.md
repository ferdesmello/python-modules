# Python Modules
Introduction to Python programming over _many_ modules.

| Module | Title | Theme | Topics |
|---|---|---|---|
| **[Module 00](./module00)** | Growing Code | Python Fundamentals | Variables, expressions, basic functions, control flow, type annotations. |
| **[Module 01](./module01)** | Code Cultivation | Object-Oriented Programming (OOP) | Classes, objects, methods, encapsulation, inheritance, basic system desig |
| **[Module 02](./module02)** | Garden Guardian | Exceptions Handling | Data validation, raise, multiple error types, custom exception classes, try/except/finally blocks |
| **[Module 03](./module03)** | Data Quest | Data Structures & Collections | Lists, tuples, dictionaries, sets, basic data manipulation and performance tradeoffs |
| **[Module 04](./module04)** | Data Archivist | Package & Import Management | Reading and writing files, stream management, error handling, file security/vaults. |
| **[Module 05](./module05)** | Code Nexus | Polymorphic Data Streams | Abstract base classes (ABCs), method overriding, subtype polymorphism, stream processing pipelines. |
| **[Module 06](./module06)** | The Codex | Package & Import Management | Package initialization (`__init__.py`), absolute vs. relative imports, import pathways, circular dependencies. |
| **[Module 07](./module07)** | Data Deck | Abstract Architecture & Design Patterns | Abstract classes, interfaces, factory patterns, modular architecture. |
| **[Module 08](./module08)** | The Matrix | Data Engineering Environments & Setup | Virtual environments (`venv`), package management, system environment configuration. |
| **[Module 09](./module09)** | Cosmic Data | Data Validation with Pydantic | Pydantic models, type validation, custom field validation rules, nested structures. |
| **[Module 10](./module10)** | FuncMage Master | Functional Programming | First-class functions, lambdas, higher-order functions, scope & closures, decorators. |
